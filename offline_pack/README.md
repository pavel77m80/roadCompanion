# Offline Story Pack + GPS Playback

Один из инкрементов Road Companion: офлайн-бандл поездки с историями от POI и
UI-независимым GPS-движком. Весь инкремент работает **без сети**: данные бандла
читаются только из локальных файлов, а ядро не импортирует сетевые модули
(проверяется тестами).

> Конфиденциальность: конкретный бандл (маршрут, координаты POI, источники)
> собран локально из приватного эксперимента и **в git не коммитится**
> (см. `.gitignore`; `offline_pack/trip_bundle/` собирается скриптом).
> В репозитории остаются только нейтральные синтетические тесты и инструменты.

## Состав

```
offline_pack/
├─ companion_core/
│  ├─ bundle.py          # загрузка и валидация бандла (без сети)
│  ├─ playback.py        # GPS playback engine: Fix, TripPlayer, RouteGeometry (без сети)
│  ├─ preflight.py       # аудит происхождения карточек → preflight_report.json
│  └─ build_bundle.py    # отбор POI + генерация trip_bundle/ и selection_report.json
├─ trip_bundle/          # ОФЛАЙН-БАНДЛ (собирается локально, в git не входит)
├─ field/                # инструменты полевой проверки (GPS-рекордер, replay, метрики)
├─ tests/                # unittest-тесты (валидация + движок + без сети)
├─ check_bundle.py       # быстрая загрузка бандла (см. ниже)
├─ simulate_trip.py      # воспроизводимая СИМУЛЯЦИЯ поездки (не реальный авто)
└─ *.json                # отчёты аудита и лог симуляции (локальные)
```

## Запуск

Требуется Python 3.10+ (используются только модули стандартной библиотеки).

```powershell
# 1. Сборка бандла локально (отбор из артефактов экспириента; без сети)
python -X utf8 offline_pack\companion_core\build_bundle.py

# 2. Валидация загрузки бандла
python -X utf8 offline_pack\check_bundle.py

# 3. Тесты (без обязательного trip_bundle; бандл-зависимые — пропускаются)
python -m unittest discover -s offline_pack\tests -v

# 4. Симуляция поездки → simulation_log.json
python -X utf8 offline_pack\simulate_trip.py
```

## Правила движка (summary)

- Фиксация проходит фильтр точности (по умолчанию `min_gps_accuracy_m=50`),
  телепорт-фильтр (`max_jump_m_per_s=120`) и монотонность времени.
- История срабатывает, если: прямое расстояние до POI ≤ `trigger_radius_m`,
  поездка *приближается* к позиции истории вдоль маршрута, поездка не в съезде,
  история не показана ранее (однократность) + защитный кулдаун.
- Съезд (`TRIP_OFF_ROUTE`, порог `off_route_threshold_m=250`, 3 фиксации подряд)
  временно отключает триггеры; возвращение (`TRIP_RESUMED`) восстанавливает.
- Проехали историю без срабатывания → `STORY_MISSED`.
- Состояние движка сериализуется/восстанавливается (`export_state/restore_state`)
  и подходит для переноса логики в мобильное приложение.

## Ограничения этапа

- ORS (`openrouteservice`) не тестировался: `ORS_API_KEY` не задан.
- Маршрут диктуется OSRM-геометрией стадии 1; радиусами триггеров управляет
  автоподбор `max(ручной, ceil((dist_line_m+75)/25)*25)`.
- Длительность истории вычисляется из объёма текста (~2 слова/с);
  фактическая диктовка зависит от темпа рассказчика.
- Истории содержат только факты из сохранённых источников; интерпретации помечены
  `kind=interpretation`, недостатки данных — в `manifest.incomplete_data`.
- Симуляция генерирует синтетические GPS-фиксации и **не заменяет** тест на
  реальном автомобиле.
